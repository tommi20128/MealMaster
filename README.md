# Resepti- ja ruokalistasovellus

Tämä projekti on OAMK:n kouluprojektina toteutettu ryhmätyö. Projektin tavoitteena oli suunnitella ja toteuttaa sovellus, jonka avulla käyttäjä voi tarkastella reseptejä ja suunnitella niiden pohjalta ruokalistaa.

## Projektista

Sovelluksessa käyttäjä voi esimerkiksi:

* selata ja tarkastella reseptejä
* lisätä reseptejä ostoslistalle
* suunnitella tulevia aterioita

Projekti toteutettiin ryhmätyönä, ja kehityksen aikana harjoiteltiin muun muassa ohjelmistokehitystä, versionhallintaa ja tiimityöskentelyä.
